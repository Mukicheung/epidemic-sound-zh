# 验证范围

日期：2026-10-16。公开版本 0.1.3 的运行逻辑沿用 0.1.2；新增发布元数据和项目结构。

## 自动检查

`npm test` 验证原始 textContent、href、输入和表单值、点击读取值、动态内容、曲目/艺人保护、节点复用、样式恢复及重复注入。

测试环境使用 jsdom。它不能证明真实浏览器布局或 Epidemic Sound 服务端行为。构建检查确认油猴与扩展使用相同运行代码。

## 浏览器观察

- 本地真实浏览器测试页：中文按钮点击仍读取英文 Download，前置 SVG 图标约 16px；动态标签和快捷切换可用。
- 实站 0.1.2：已确认安装；导航、搜索提示及情绪/曲风/人声/时长等筛选文字显示中文。
- 实站情绪筛选仍使用英文 URL 参数；观察到结果列表返回。
- 播放器观察到播放状态和进度。下载窗口可以打开，完整曲目、混音、文件格式和下载按钮中的已收录词条显示中文。
